# 主页皮肤

动手前先读,不靠记忆:
- `docs/主页皮肤组成规范.md` —— 5 层组成、尺寸、底板内容安全区、背景规则 1–13
- `docs/主页皮肤验收清单.md` —— 从完成稿量出来的验收阈值 + 每条出自用户哪次反馈
- 本套的风格卡 `docs/风格卡/<套名>.md`(没有就按第 1 步先写)
同时按 `save-tokens` 处理图片;出图按 `gemini-batch-image`(Nano Banana Pro,只走批量)。

## 开新皮肤时用户给什么(缺了就问,别的不用要)

1. **角色** —— 主题跟着角色定。
2. **配色参考** —— 直接照角色的配色方式(量配色比例:主色 / 辅色 / 点缀占比、明度饱和度),写进风格卡。
3. **级别** —— 用户说 A 还是 S。
4. **放 Figma 的哪一页** —— 用户给位置。

## 级别决定做什么

| 级别 | 背景物件动效 | 装扮 |
|---|---|---|
| **S** | 有(见「动效」) | 主页皮肤(4 种底板)+ 头像框 + 称号 + 名字底 + 气泡框 + 入口图标 |
| **A** | 无,背景只出静态 | 主页皮肤(4 种底板)+ 入口图标 + 头像框**或**称号(用户说哪个) |

**S 级一律分层出图**:背景里要动的物件,和头像框 / 称号 / 名字底 / 气泡框上的装饰,都要做动效,所以出图时就分层出(或出完拆开):每个要动的东西单独一层(透明底,结构完整),底下的背景 / 底框补全,不能和底图画死在一张里。A 级背景和装扮出整张静态即可。

## 动效(只 S 级)

从中秋录屏(S17 1528:337)量出来的,幅度已换算到 2436 画布(×约 1.3,粗估):
- **所有物件同一个 4 秒循环**,同一条曲线:开头约 0.4s 先小幅反向(前摇)→ 约 2.5s 到最大 → 缓回 4s 归零,无停顿。不是对称正弦。
- **摆动类**(挂着的、有生命的):绕挂点 / 底部摆,末端甩得比根部大。飘带末端 ≈15–20px;灯笼 ≈15px(上下两个错开约 0.4s);胖兔子耳朵 ≈30px、身体 ≈15px。
- **浮动类**(小角色、小物):上浮再回落,竖向 ≈25px(顶部小兔)。
- **漂移类**(云、蝴蝶):1.4–3.4s 间水平平移 3–5px,近处的大云幅度大、远处小云小(视差)。
- **不动**:窗景 / 主建筑、枝干本体、压在物件上的按钮、底板、导航。没有闪烁、缩放呼吸。
- 拆层:每个要动的物件单独一层,挂点 / 旋转中心写进 `图层坐标与动效.json`;物件下面的背景要补全(动起来不露洞)。

## 流程

1. **收素材 → 风格卡**:角色和配色参考拷进 `docs/风格卡/<套名>_参考/`,写风格卡(主色 HEX、配色比例、材质、元素、禁止项、提示词底稿)。要点 3–5 行给用户看一眼再出图。
2. **背景**(2436×1125):角色中线 x=440;主题装饰(主视觉)集中在左区,装饰摆在底板缝、上下、右边缘、主视觉外圈,不进底板安全区。每次都出「叠底板合成图 + 无底板图」一起看。
   - **整屏是一个连续场景,左右不能割裂**(10-29 用户指出):底纹 / 花纹 / 渐变 / 光照从左铺到右边缘;有一条贯穿全宽的地面 / 地平线 / 底部纹带;顶边、底边、最右侧也有装饰(彩带、幕边、枝叶、漩涡纹、星串),落在底板间缝和四周。底板区只是**更浅、细节更少**,仍是同一场景同一透视——不能是一块平涂空白板。
   - 提示词里**不要写**「右边留空 / plain empty background on the right」,要写「continuous scene across the full width, calmer and lighter behind the panels」。参考完成稿:S17 中秋纯背景(1528:337)、S 级虚拟歌姬 `exports/nano/s18_vsinger_S/切图/01_主页背景`。S 级:要动的物件(见动效表)单独成层出图,别和背景画死在一起。
3. **信息底板**:信息 902×864、窄 347×862、中 686×864、宽 1260×862(都指看得见的部分);第一张左边缘 x=880、y=78,间距 50,屏序 信息 → 窄 → 中/宽。**每套单独设计、和背景一起出小样**(10-29):不沿用别的套或同主题别的级别(A 级不能拿 S 级底板),出背景小样时合成图里就放本套新底板。**信息底板不画头像位**(10-29):左上头像 256 区域不做头像框 / 头像槽 / 凹口设计,头部和主体照常铺过去,头像由游戏叠上;提示词写「no avatar slot, no empty frame in the top-left corner」,版式参考图也不画那个方块。每块 = 头部 + 主体;画布四周外扩 40px 放投影,强度照机甲 R3(投影量≈1.9 / 伸出≈33px),所有底板投影一致;外轮廓干净,不是渐变。
4. **底部导航**:2436×108,y=1017。
5. **装扮**(按级别那张表做哪几件):头像框 256、名字底 447×130、气泡框 195×133、称号 304×72、入口图标 300(卡片 226×179@(37,60) 圆角 30 描边 5,外框只一圈纯色)。拆层时每个部件结构完整,不按矩形硬切;抠绿后半透明边去绿。S 级装扮的装饰件(主装饰、小呼应、星点等)各自分层出,底框单独一层,动效参照上面「动效」一节(同 4 秒循环)。
6. **切图**:每段一个文件夹,1x/2x × 原位PNG/紧边PNG + `图层坐标与动效.json` + 1x/2x `A级静态.png`(格式照 V8);S 级动效物件各自一层,json 里写动效参数。现成脚本可复制改:`exports/nano/s18_wing_A_mecha/cut_final.py`(切图)、`r3_hd.py`(高清 + 投影)、`exports/nano/s18_vsinger_S/decor/split_v2.py`(装扮拆层)。
7. **验收(必跑)**:`python dev/lite/skin_check.py <切图文件夹> [--color-ref 配色参考图]`
   - 有 ✗ 先修再交;△ 逐条确认,回复里一句话说明。
   - 看一次 `_验收合成.jpg`(先 `dev/lite/shot.py` 缩小),按清单 B 表人眼核对。
8. **交付 —— 只交 Figma**(不出 unitypackage、不碰主工程):
   - 放到用户给的那一页,版式照 661:2069 的 S / A 分区;矩形用 2x 坐标 ÷2;同版本只留一个分区,新版本另起分区,不覆盖以前的方案。
   - 装扮备份到 xisi 1:4 对应分区(先比哈希防重复)。
   - 回复给本地完整路径 + Figma 节点链接 + 「验收:✗0 / △n(说明)」。

## 用户给了新反馈

先把它归到验收清单的某一行(改阈值或加一行;能量化的同步改 `dev/lite/skin_check.py`),再改图。这样下次自动查得出来,不靠记住。
