## 流程

1. **收素材 → 风格卡**:用户给的图按用途拷进 `docs/风格卡/<套名>_参考/`(主题设定 / 配色参考 / 范本 / 草图),写风格卡(主色 HEX、材质、元素、禁止项、提示词底稿)。用户给了配色参考就量 HSV 分布写成数值。要点 3–5 行给用户看一眼再出图。
2. **背景**(2436×1125):角色中线 x=440;装饰只摆在底板之间的缝、上下、右边缘、主视觉外圈(底板位置见第 3 步),被底板盖住的地方不放主要元素。每次都出「叠底板合成图 + 无底板图」一起看。
3. **信息底板**:信息 902×864、窄 347×862、中 686×864、宽 1260×862(都指看得见的部分);第一张左边缘 x=880、y=78,间距 50,屏序 信息 → 窄 → 中/宽。每块 = 头部 + 主体;画布四周外扩 40px 放投影,强度照机甲 R3(投影量≈1.9 / 伸出≈33px),所有底板投影一致;外轮廓干净,不是渐变。
4. **底部导航**:2436×108,y=1017。
5. **装扮**:游戏内尺寸 头像框 256、名字底 447×130、气泡框 195×133、称号 304×72、入口图标 300(卡片 226×179@(37,60) 圆角 30 描边 5,外框只一圈纯色)。拆层时每个部件结构完整,不按矩形硬切;抠绿后半透明边去绿。
6. **切图**:每段一个文件夹,1x/2x × 原位PNG/紧边PNG + `图层坐标与动效.json` + 1x/2x `A级静态.png`(格式照 V8)。现成脚本可复制改:`exports/nano/s18_wing_A_mecha/cut_final.py`(切图)、`r3_hd.py`(高清 + 投影)、`exports/nano/s18_vsinger_S/decor/split_v2.py`(装扮拆层)。
7. **验收(必跑)**:`python dev/lite/skin_check.py <切图文件夹> [--color-ref 配色参考图]`
   - 有 ✗ 先修再交;△ 逐条确认,回复里一句话说明。
   - 看一次 `_验收合成.jpg`(先 `dev/lite/shot.py` 缩小),按清单 B 表人眼核对。
8. **交付**:
   - 拼进 Figma 对应页,版式照 666:2091(左上图标 300、y=626 三屏 x=146/2707/5317、下排底板平铺);矩形用 2x 坐标 ÷2;同版本只留一个分区,新版本另起分区,不覆盖以前的方案。
   - 装扮备份到 xisi 1:4 对应分区(先比哈希防重复)。
   - 回复给本地完整路径 + Figma 节点链接 + 「验收:✗0 / △n(说明)」。
