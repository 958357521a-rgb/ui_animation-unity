# 主页皮肤 / 装扮交付验收

标准写在 `docs/主页皮肤验收清单.md`(从完成稿 V8 和机甲 R3 通过版量出来的阈值 + 用户反馈出处)。

1. 动手改图前先读清单 A/B 两表,按里面的标准做,不靠记忆。
2. 交付前跑:`python dev/lite/skin_check.py <切图文件夹> [--color-ref 参考图]`
   - 有 ✗:先修,修完重跑,不把 ✗ 交给用户。
   - △:逐条确认,在回复里一句话说明为什么可以接受。
3. 看一次合成图:`python dev/lite/shot.py <切图文件夹>/_验收合成.jpg`,按清单 B 表逐条核对。
4. 回复用户时附一句「验收:✗0 / △n(说明)」。
5. 用户给了新反馈:先改清单(加一行或改阈值;能量化的同步改 `skin_check.py`),再改图。
