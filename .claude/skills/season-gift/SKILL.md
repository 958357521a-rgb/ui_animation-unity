# 赛季活动礼包

动手前先读,不靠记忆:
- `docs/赛季礼包规范.md` —— 标准稿节点、每期要设计的部件清单、固定位置尺寸、设计要求、Figma 交付版式
- 本期风格卡 `docs/风格卡/<主题>.md`(没有就按第 1 步先写;同主题已有主页皮肤 / 扭蛋的风格卡就直接沿用)
- 参考截图 `docs/风格卡/赛季礼包_参考/`(S18 标准稿 + S16 风格表现;看过就用文字说,别再截原稿)
同时按 `save-tokens` 处理图片和 Figma;出图按 `gemini-batch-image`(Nano Banana Pro,只走批量)。

## 开新一期时用户给什么(缺了就问,别的不用要)

1. **主题**:主题名 / 角色(立绘),或者指一份已有风格卡。
2. **奖励清单**:8 个礼包各自的物品(决定 8 个物品图标),以及主题货币是什么。
3. **礼包名和价格**:没给就先用占位文字(「XX礼 Ⅵ」「¥ 98」「8.8折」),文字都是文字层,之后改起来很方便。
4. **Figma 交付位置**:用户会给链接。

## 规矩(用户定的)

- **版式全照 S18 机甲风礼包**(733:4274):2×4 卡片、卡片和各部件的位置大小固定,每期不改;返回 / 左侧页签 / 钻石条 / 通用弹窗框沿用,不重新设计。
- **页签区 / 礼包区 / 人物区锁死**(规范第 3 节表格):小样和完成稿都不许挪、不许压缩礼包区。左侧页签是通用组件,**只改选中页签名 = 本期礼包名**,别的页签不动、不编。所以小样也**不让 AI 出整页**:AI 只出背景、单张卡片样式、物品图标,脚本按坐标拼。
- **卡片内部结构也锁死**(规范第 3 节「卡片内部结构」):角标 / 标题 / 图标底 / 信息行 / 价格的位置大小照 S18。新卡片框 = 拿 S18 卡片框原图当底图让 AI 只换配色纹样;**信息行只改颜色,解锁条只改底板颜色**,其余(图标、细线、文字位置)都不动——这两件用脚本给 S18 原件换色即可,不用 AI 出。
- **每期跟主题重新设计**:背景、卡片框(一整张:外框 + 标题栏 + 图标底 + 价格按钮,不拆)、折扣角标、价格按钮、置灰遮罩、已售罄版卡片框、弹窗卡片、主题货币图标、8 个物品图标。角标和价格按钮跟卡片框一起换配色,角标外形保持 S18 椭圆。信息行、解锁条只换色(见上条)。
- **配色别跟主题不搭**:颜色从风格卡取,叠到本期背景上检查。
- **卡片(信息底板)要有设计感**:主题纹样标题栏 + 角落小装饰 + 有质感的暖色价格按钮,不能是纯色圆角框。
- **只交 Figma**:不出 unitypackage,不碰主工程。

## 流程

1. **风格卡**:主题参考拷进 `docs/风格卡/<主题>_参考/`,写风格卡(主色 HEX、配色比例、材质、标题栏纹样、角落装饰元素、禁止项、提示词底稿)。另外写 3–5 行「礼包怎么套这个主题」(标题栏用什么纹样、价格按钮什么色、角标什么色),先给用户看一眼再出图。
2. **卡片框 + 角标 + 价格按钮**(一起出,小样阶段):每个方案 = 背景(无 UI 无人物)+ 单张卡片样式。卡片用 `dev/season_gift/card_jobs.py`:S18 卡片框 + 角标原件拼成结构底图,AI 只换配色纹样(轮廓、各部件位置大小不动,不写字),2–4 个方案各出 2 张;逐张核对角标形状和部件位置,变了的不用。再用 `dev/season_gift/compose.py` 按规范第 3 节坐标拼整页小样(通用页签只改选中名,信息行 / 解锁条用 S18 原件换色)。用户选定后再出配套件:置灰遮罩、已售罄版卡片框、弹窗卡片、主题货币图标;信息行和解锁条照小样的换色结果切图。
3. **物品图标** 8 张:按奖励清单一次批量出,同一光照、视角、描边;透明底,228×172 画布里居中、留 8px 边。
4. **背景**:2436×1125 整屏连续场景,卡片区 x 440–1940 更安静;立绘放右侧(S18 1174×1174 @(1502,-18)),**图层在卡片下面,不能压卡片**;人物脸、手落在卡片右边缘 x=1937 以右。
5. **拼合检查**:按规范第 3 节的坐标把 8 张卡(各状态都要有:至少 1 张折扣、1 张已售罄、1 张未解锁)和立绘拼到背景上(顺序:背景 → 立绘 → 卡片),出一张合成图,对照规范第 4 节逐条看。用 `dev/lite/shot.py` 缩小后只看这一次。
6. **切图**:每件透明 PNG,尺寸跟规范第 2 节一致(1x;另出 2x),文件名用组件名(`卡片框.png`、`折扣角标.png`、`物品图标_宝石礼盒.png`…)。文字不画进图。
7. **交付到 Figma**(用户给的那一页):照规范第 6 节做分区「礼包切图」:完成页 + 组件板(母件 `礼包卡片` 四个状态,属性 标题 / 价格 / 物品图标)+ 详情弹窗两态。新版本另起分区,不覆盖。回复给本地路径 + Figma 节点链接 + 第 4 节检查结果(一行一条)。

## 用户给了新反馈

先改进 `docs/赛季礼包规范.md`(固定位置写进第 3 节,设计要求写进第 4 节,注明日期),再改图。这样下一期自动照着做,不靠记住。
