# 扭蛋主题背景

每期扭蛋都要出一张和本期角色有关联的背景。版式固定(模板 = S18「圣羽降临」),每期只换场景内容和配色。
通用规范:`docs/扭蛋背景规范.md`(版式表、场景结构、配色目标、质感要求)。动手前先读它,不靠记忆。
同时按 `save-tokens` 技能处理图片:参考图只看一次,写成风格卡后就用文字和路径。

## 每期流程

1. **收素材,自动归档**:把用户给的图按用途拷进 `docs/风格卡/扭蛋_<期名>_参考/`,命名为 `角色设定_*`、`质感参考_*`、`背景初版_待改`(有的话)。不要让用户自己整理。
2. **拆角色 → 写本期风格卡** `docs/风格卡/扭蛋_<期名>.md`(格式照 `扭蛋_虚拟歌姬.md`,≤20 行):
   - 角色识别色(HEX)、3–5 个标志物(会变成场景结构,不是贴图)、人设关键词。
   - 场景方案:「这个角色在哪里最闪耀」→ 左框景 / 右框景 / 舞台 / 远景各放什么。
   - 背景配色:底色按模板走高调浅色;本期主色相只上在道具、灯带、舞台边;压重色和对比色各取什么。
   - 质感参考只取材质和细节密度,不取它们的明暗。
   - 有角色版:角色放在右框景的屏幕 / 全息框 / 门里(规范 §3.5)。
   - 风格卡写完给用户看一眼要点(3–5 行),再出图。
3. **出图**:用 `gemini-batch-image` 技能(Nano Banana Pro,批量)。
   - 提示词 = 风格卡「提示词底稿」+ 版式句:`calm open empty center for a character model, large themed props framing left and right, circular stage platform on lower half, low horizon, clean sky in upper area, no text`。
   - 参考图用文件路径传:模板干净背景 `docs/扭蛋背景规范_参考/圣羽降临_干净背景.png`(构图),加上本期 `_参考/` 里的角色设定和质感参考。
   - 比例选最接近 2436:1125 的宽幅,出完等比铺满 2436×1125 并居中裁切。一次出 4 张,存到 `exports/gacha_bg/<期名>/`,对话里只留路径。
   - 有角色版:在选定的无角色版上做局部重绘,只改 character_slot 区域,别的不动。
4. **验收(必跑)**:`python dev/gacha_bg/gacha_check.py <图>`。
   - 有 ✗ 先修再交;! 写进交付说明。
   - 多张候选先 `python dev/lite/sheet.py exports/gacha_bg/<期名>/` 拼成一张发给用户挑,不逐张 Read。
5. **交付**:用发文件的工具把选中的图和 `_遮罩.png` 发给用户;用户要放进 Figma 的话,放在模板画板 951:2402 旁边。

## 常见问题(从「虚拟歌姬」初版总结)

- 整张图都是同一个饱和色 → 脚本「饱和色总量」✗。主色只上在灯带 / 霓虹边 / 舞台边,底色回到浅色。
- 质感糊、像蒙了一层柔光 → 风格卡写明每种材质各自的高光,提示词里点名材质。
- 地面一大片空 → 舞台加光圈 / 倒影 / 星形台,但按钮背后保持平稳。
- AI 写的字会变形 → 背景不出字,标题和招牌字后期单独做。

## 改规范

版式或配色目标变了:改 `dev/gacha_bg/layout.json`,同步 `docs/扭蛋背景规范.md` 的表,然后用模板干净背景跑一次脚本,确认模板自己仍然全部通过。
