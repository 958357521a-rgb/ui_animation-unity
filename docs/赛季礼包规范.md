## 4. 设计要求(用户 10-30)

1. **配色跟主题**:卡片框、角标、价格按钮、信息行、印章的颜色从本期风格卡取;交付前叠到本期背景上看一眼,色相不能跳出主题(比如紫蓝主题里出现大块暖橙底)。例外:已售罄印章 S16 / S18 都是绿色,当作状态色沿用。
2. **卡片(信息底板)要有设计感**:不能是纯色圆角矩形。至少有 ① 带主题纹样的标题栏(S18 机翼、S16 花朵和棒棒糖)② 角上 / 边上的小装饰(星点、刻线、挂坠)③ 有质感的价格按钮(渐变 + 高光 + 小装饰,S18 左下四角星)。
3. **角标、价格按钮跟卡片框一起设计**:每期跟着卡片底板改样式,但**位置和大小固定**(见第 3 节)。
4. **价格按钮是全卡最亮的暖色**(S18 黄、S16 橙),和卡片主体拉开对比;中间图标底是浅色,物品图标要看得清。
5. **物品图标**:每期按用户给的奖励清单做,同一套 8 张光照、视角、描边一致;货币类跟主题。
