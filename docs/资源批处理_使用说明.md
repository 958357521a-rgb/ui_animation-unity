# 资源批处理 · 使用说明(5 分钟看懂)

## 它是干什么的

把一批**切好图**的 UI 资源(比如新头像框)一次处理完:

1. **从 Figma 拿图**:在 Figma 里选中资源,点一下就发到工作台(不用一张张导出)。
2. **AI 换风格**(可选):按统一的风格重绘,尺寸和轮廓不变。
3. **自动检查**:编号重名、尺寸不对、缺透明通道……有问题标红。
4. **加动效**:每个部件选一种——晃动、浮动、抖动、呼吸、闪烁、变色,调幅度和快慢,左边能直接预览。
5. **出包**:生成 Unity 能直接导入的 `.unitypackage`,文件已经按主工程的位置放好。

能处理五类装扮:**头像框、聊天气泡框、称号、昵称框、主页皮肤**(加一个「通用 · 原地换图」)。所有规则目前是**暂定的**,见 `docs/资源批处理_暂定规范.md`。

## 先看一遍示例(不用 Figma、不用 AI)

1. 打开工作台(桌面图标「BUD UI Studio」),任务首页顶栏点 **「资源批处理」** 页签(编辑界面工具栏的「资源批处理」也会跳过来)。
2. 让 Claude 运行 `python dev/pipeline_demo.py --all --job`(或者自己在文件夹里打开终端运行)。五类各有一个示例,素材都是主工程里的真实资源。
3. 刷新「资源批处理」页面,左边会出现 **「示例 · 头像框_9036」「示例 · 聊天气泡_9038」「示例 · 称号_9043」「示例 · 昵称框_9019」「示例 · 主页皮肤_9045」**:
   - 左边小窗口是动效预览(部件在晃、在变色、在闪);
   - 表格里每行一张切图:原图、AI 新图、角色、动效参数;
   - 点 **「规则检查」** → 再点 **「生成 unitypackage」**,会告诉你包在哪、还要手动加哪条配置。
4. 示例生成的包和说明也放在 `samples/pipeline/<示例>/示例输出/`,可以直接拿去 Unity 里导入看看。

工作台刷新(Ctrl+R)会停在刷新前的界面:资源批处理页签里打开的任务、任务首页、编辑界面都保持原样。

## 正式用:从 Figma 到 Unity

**第一次准备(只做一次)**
- 「资源批处理」页签顶栏填**主工程路径**(含 Assets 的那层),点保存;记下顶栏的**配对码**。
- 桌面版 Figma:菜单「插件 → 开发 → 从清单导入」,选工作台文件夹里的 `figma-plugin/manifest.json`。
- 在 Figma 里运行插件 **BUD UI Studio →「资源批处理」**,填工作台地址(默认 `http://localhost:8791`)和配对码,点「测试连接」。

**每次处理**
1. Figma 里把每个资源做成一个画框,名字带编号(如「头像框_40」);里面每个部件一个子图层,按名字区分角色(见下表;页面上也能改)。
2. 选中这些画框 → 插件里点 **「发送选中的资源到工作台」**。
3. 工作台「资源批处理」→ 左下 **新建任务**(标准选对应的类型,新增)→ **「从 Figma 收件」** 选刚发来的那批。
4. 要换风格就勾「AI」→ 点 **「AI 重绘」**(要本机装好 ComfyUI,见 ONBOARDING 第 7 节;没装就跳过)。
5. 给部件选动效、调参数,看左边预览。气泡底图要填**九宫格**边距;每个资源上方展开**「配置条目字段」**填名称、说明、颜色。
6. **「规则检查」** → 红色的要改 → **「生成 unitypackage」**。
7. Unity 里双击包导入;按包旁边 README 的提示,把那条配置加进对应的配置文件(头像框 `HeadCycleConfig.json`、气泡 `ChatBubbleConfig.json`、称号 `TitleConfig.json`、昵称框 `NicknameConfig.json`、主页皮肤 `ProfileThemeConfig.json`)。
8. 想在 Figma 里看结果:**「放回 Figma」** → 插件里点 **「取回处理结果」**,新图会摆在原资源右边。

**各类资源在 Figma 里怎么摆**(画框名带编号;子图层名决定角色)

| 类型 | 画框 | 子图层名 → 角色 |
|---|---|---|
| 头像框 | 256×256 | `底框`、`预览`、`上_xxx`(上层特效)、`下_xxx`(下层特效) |
| 聊天气泡框 | 随意 | `底图`(九宫格)、`图标`(约 195×133)、`预览`(可选);其余 = 角饰,自动归到最近的角(或写 `左上_xxx` / `右上_` / `左下_` / `右下_`) |
| 称号 | 304×72 | `图标`(整张称号);其余 = 部件(要动的单独切);只有图标 = 静态称号 |
| 昵称框 | 447×130 | `框`(就是图标)、`预览底图`;其余 = 叠在框上的部件 |
| 主页皮肤 | 2436×1125 | `背景`、`底栏` / `底栏上层`、`卡片1_头部` / `卡片1_主体` / `卡片1_位置`(1~5 五种卡片)、`合成效果图`、`缩略图`(300×300);其余 = 装饰(自动分到左上 / 左下) |

`参考xxx` / `_xxx` 开头的图层不导出。交付包文件名是英文的(Unity 解包不认中文文件名)。

**管理任务**:左边栏顶上 **「▦ 任务中心」**,任务按类型分区(左边栏也按类型分组,点组名折叠、点「＋」新建这一类)。每个任务能打开、编辑信息(名称、备注)、复制、导出(任务包 .zip 发给同事 / 下载交付包)、标记完成、删除(先进回收站,能恢复)。同事发来的任务包用「导入任务」。

**替换已有的图**:新建任务时选「替换」,每张切图填要替换的主工程路径(必须同尺寸),出的包导入后原地换掉,引用不断。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 页面提示连不上本地服务 / 服务是旧版 | 任务管理器结束 `pythonw.exe`,再双击桌面「BUD UI Studio」 |
| 插件「测试连接」失败 | 工作台要开着;配对码看「资源批处理」页面右上角;地址是 `http://localhost:8791` |
| Figma 插件菜单里没有「资源批处理」 | 「插件 → 开发 → 从清单导入」重新导一次 `figma-plugin/manifest.json` |
| 检查说「缺编号」 | 资源名末尾加数字,或在页面上资源名旁边填编号 |
| 检查说「主工程里已有编号 xx」 | 换一个没用过的编号;要改旧的就新建「替换」任务 |
| AI 重绘失败 | 本机 ComfyUI 没开或没装;失败的会用原图,不影响出包 |
| 动效预览和 Unity 里不完全一样 | 预览是浏览器近似效果,以 Unity 为准 |

更细的说明:`dev/pipeline/README.md`(给 Claude / 程序看的)。
