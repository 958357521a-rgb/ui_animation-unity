# 资源批处理 · 使用说明(5 分钟看懂)

## 它是干什么的

把一批**切好图**的 UI 资源(比如新头像框)一次处理完:

1. **从 Figma 拿图**:在 Figma 里选中资源,点一下就发到工作台(不用一张张导出)。
2. **AI 换风格**(可选):按统一的风格重绘,尺寸和轮廓不变。
3. **自动检查**:编号重名、尺寸不对、缺透明通道……有问题标红。
4. **加动效**:每个部件选一种——晃动、浮动、抖动、呼吸、闪烁、变色,调幅度和快慢,左边能直接预览。
5. **出包**:生成 Unity 能直接导入的 `.unitypackage`,文件已经按主工程的位置放好。

现在只有**头像框**是完整的;别的资源(主页皮肤等)规则还没定。所有规则目前是**暂定的**,见 `docs/资源批处理_暂定规范.md`。

## 先看一遍示例(不用 Figma、不用 AI)

1. 打开工作台(桌面图标「BUD UI Studio」),点工具栏右边的 **「资源批处理」**。
2. 让 Claude 运行 `python dev/pipeline_demo.py --job`(或者自己在文件夹里打开终端运行)。
3. 刷新「资源批处理」页面,左边会出现 **「示例 · 头像框_9036」**:
   - 左边小窗口是动效预览(部件在晃、在变色、在闪);
   - 表格里每行一张切图:原图、AI 新图、角色、动效参数;
   - 点 **「规则检查」** → 再点 **「生成 unitypackage」**,会告诉你包在哪、还要手动加哪条配置。
4. 示例生成的包和说明也放在 `samples/pipeline/avatar_frame_9036/示例输出/`,可以直接拿去 Unity 里导入看看。

## 正式用:从 Figma 到 Unity

**第一次准备(只做一次)**
- 「资源批处理」页面右上角填**主工程路径**(含 Assets 的那层),点保存;记下右上角的**配对码**。
- 桌面版 Figma:菜单「插件 → 开发 → 从清单导入」,选工作台文件夹里的 `figma-plugin/manifest.json`。
- 在 Figma 里运行插件 **BUD UI Studio →「资源批处理」**,填工作台地址(默认 `http://localhost:8791`)和配对码,点「测试连接」。

**每次处理**
1. Figma 里把每个资源做成一个画框,名字带编号(如「头像框_40」);里面每个部件一个子图层,按名字区分:`底框`、`预览`、`上_xxx`(上层特效)、`下_xxx`(下层特效)。
2. 选中这些画框 → 插件里点 **「发送选中的资源到工作台」**。
3. 工作台「资源批处理」→ 左下 **新建任务**(标准选「头像框」,新增)→ **「从 Figma 收件」** 选刚发来的那批。
4. 要换风格就勾「AI」→ 点 **「AI 重绘」**(要本机装好 ComfyUI,见 ONBOARDING 第 7 节;没装就跳过)。
5. 给部件选动效、调参数,看左边预览。
6. **「规则检查」** → 红色的要改 → **「生成 unitypackage」**。
7. Unity 里双击包导入;按包旁边 README 的提示,把那条配置加进 `HeadCycleConfig.json`。
8. 想在 Figma 里看结果:**「放回 Figma」** → 插件里点 **「取回处理结果」**,新图会摆在原资源右边。

**替换已有的图**:新建任务时选「替换」,每张切图填要替换的主工程路径(必须同尺寸),出的包导入后原地换掉,引用不断。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 页面提示连不上本地服务 / 服务是旧版 | 任务管理器结束 `pythonw.exe`,再双击桌面「BUD UI Studio」 |
| 插件「测试连接」失败 | 工作台要开着;配对码看「资源批处理」页面右上角;地址是 `http://localhost:8791` |
| Figma 插件菜单里没有「资源批处理」 | 「插件 → 开发 → 从清单导入」重新导一次 `figma-plugin/manifest.json` |
| 检查说「缺编号」 | 资源名末尾加数字,或在页面上资源名旁边填编号 |
| 检查说「主工程里已有编号 xx」 | 换一个没用过的编号;要改旧的就新建「替换」任务 |
| AI 重绘失败 | 本机 ComfyUI 没开或没装;失败的会用原图,不影响出包 |
| 动效预览和 Unity 里不完全一样 | 预览是浏览器近似效果,以 Unity 为准 |

更细的说明:`dev/pipeline/README.md`(给 Claude / 程序看的)。
