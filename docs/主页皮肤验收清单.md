## B. 人眼看合成图(脚本判断不了)

1. 版式:角色中线 x=440,首张底板左边缘 x=880、y=78,间距 50,导航 y=1017;屏序 信息 → 窄 → 中/宽。
2. 背景装饰摆在底板**间缝和四周**,不被底板盖住主体;背景花纹延伸到底板挪开后露出的地方,不留缺角。
3. 角色 / 主体不被信息底板挡脸。
4. 所有底板投影样式一致(同方向、同强度)。
5. 导航:脚本对纯色 / 简单花纹的导航会报"清晰度低",看图确认是设计本来就简单,还是真糊。导航**不能是纯平涂色条**(11-05「导航页太干净」):照 S 级深梅色底 + 大小不一的星星花纹 + 粉色顶边,本套至少有一层花纹和顶边高光。
6. 装扮部件:每个部件结构完整(不是被切掉一半的形),拆层按"一大主装饰 + 对角小呼应 + 少量星点"节奏。
7. 风格对得上风格卡(`docs/风格卡/`),没有跑去别的主题。
8. **左右不割裂**(10-29):背景是一个连续场景,底纹 / 渐变 / 地面贯穿全宽,顶边、底边、最右侧也有装饰;底板区只是更浅更静,不是平涂空白板。脚本「左右割裂」项报 △ 时重点看。
9. **底板 / 导航本套配套设计**(10-29):不沿用别的套或同主题别的级别的底板。
10. **信息底板没有头像位设计**(10-29):左上角不出现头像框 / 头像槽 / 为头像挖的凹口,头像由游戏叠上。
11. **气泡框不带尖角**(10-30,以后所有气泡框):底框是完整的圆角 / 异形框,不画指向说话人的小尖角。
12. **装扮图层名、部件名都是中文用途名**(10-30「组件全部改成带名字的」):底框 / 音响 / 大星星 / 格子旗…,Figma 里同名。
13. **星星逐颗、竖条逐根**(11-03):挨着的几颗星、一组竖条脚本按连通块查不出来,看拆层:每颗星、每根竖条各自一层(大星星_1 / 小黑星 / 竖条_1…)。**底框和静态层要单独摊开看**(放大到 2x):边上没有拆剩的描边、白渣、残影轮廓、矩形补丁——只看合成图是看不出来的。
14. **每层自身表达清楚**(11-04,参考 `docs/风格卡/装扮拆层_清晰结构.md`):底框单独看是一件完整设计(分段 / 倒角 / 高光条画全,不是挖剩的);每个部件描边闭合、色块分明、边缘利落像矢量。照机甲风拆层参考的感觉,达不到就重画,不在抠图上修。
15. **主视觉不被底板挡**(11-05「舞台被遮挡太多」):舞台 / 主视觉整组缩到左区 x<860 内,底板最多压到外圈装饰,不压主体。
16. **底板有节奏**(11-05「信息底板节奏感少了」):头部与主体明暗对比明显(深色头部 + 浅色主体或反之),一处大装饰破轮廓 + 对角小呼应,不是四边均匀一圈花边。外框描边要细(11-05「边很厚」:不要粗黑框 + 厚投影边);头部可带细花纹 / 纹理,不是纯平涂;对角小呼应要小而自然,别用突兀的整块贴片(棋盘格贴片被说「很奇怪」)。破轮廓的大装饰要和底板长在一起、有节奏(11-05 第 8 轮「被切烂了、大星星很突兀」):用一大一小两颗叠放这类成组的形,压住角的一部分并和头部描边接上,不是一颗孤零零的大形把角切掉。**破出底板框的装饰要完整保留,切图时不能按底板矩形裁掉**(11-06「被裁切掉了,超出来的不用切掉」:切图画布外扩、只裁掉和底板不相连的东西)。底板侧边的小细节别用深色刻度条(11-06「黑色的换一种表现形式」),用和头部同色系的粉色小件。破框装饰边缘要利落,外面不要一圈模糊光晕(11-06「星星外边一圈糊糊的不要」)。
17. **背景干净无噪点**(11-05):不要模糊 / 不均匀的网点、颗粒、杂点;网点只在少量形状里规整出现或干脆不要。**干净 ≠ 空**(11-05 第 7 轮「背景太干净,S 级相对干净但内容丰富」):主视觉后面要有中景 / 远景内容(淡化的舞台桁架、灯架、挂饰、光束、远处剪影),大片空白平涂不合格。**也不要纵深空间**(11-05 第 8 轮「太亮了、不要后面有空间」):照 S 级用贴近主视觉的平面舞台背板(星形大框 / 幕布 / 花纹墙 / 桁架贴在后面),不画延伸到远处的会场、地平线和透视地面;整屏明度不高于 S 级(平均明度 ≤0.86),不是发白发亮。
18. **A 级画风跟同系列 S 级一致**(11-05「绘制风格和 S 级差太多」):细且均匀的深色描边(不是粗黑贴纸描边)、柔和赛璐璐 + 光泽渐变 + 小高光、远景淡近景实的空间层次、霓虹带柔光;整体高明度粉白,不是平涂艳粉。出图时把 S 级整屏当画风参考,和 A 级小样并排看一眼再交。
19. **头像框环要细、名字底照 xisi 结构**(11-06「圈太粗了,名字底的形状和装饰物的结构节奏感不对」):头像框环带 ≤ 画布宽 5%(头像洞 ≈78%),丰富度靠破轮廓的主装饰,不靠加粗环。名字底底板是简单圆角长条(447×130 画布里约 393×90 居中,细描边,底面浅色带同色系小花纹 / 渐变),不切角、不做异形;装饰都在 130 高内:左端一组主装饰(约 80~120 宽,压住底板左端)、右上一个小件 + 右下一个小件、两三颗小闪点,中间留空放名字(xisi 1:4 名字底分区 264:5563)。左端主装饰不能是一个圆东西直接扣在角上(11-06「太直给,只是放上去,没节奏感」):要由大中小 2~3 件叠成一组(主件微倾斜 + 前面压一件 + 后面露一件),沿斜线展开,再有 1~2 颗小星 / 音符顺着底板上边或下边往里延伸,底板左端在主装饰下面有一点呼应的结构(色块 / 边饰),看起来是长在一起的。切完量一次底板实色部分:≈393×90(11-06 虚拟歌姬 A 只有 314 宽,被说「输出尺寸不对」),AI 画短了就把中间空白段横向拉宽再切。
20. **底板四条边干净**(11-06「四个信息框的边有噪点」「这里还有黑色」):放大到 2x 看四条直边,最外圈描边是连续直线,下面 / 外面没有断断续续的半截深色碎段;边内侧没有残留的深色刻度 / 竖条。AI 底板切出来先过一遍 `cut_final.clean_edges`(虚拟歌姬 A)这类处理:断崖外的半截行列抹掉、补一像素软边,伸出的星星不动。
21. **背景构图偏左、右侧有内容**(11-06「构图往左边多动一些,右边的空了得补一下」):主视觉(大星框 / 舞台 / 音箱)整组靠左,主体露在第一张底板左边;右半边不是平铺墙纸:底板之间的缝、顶边条、地面条和最右侧都要看得到东西(桁架、吊灯、挂饰、地面音箱)。已定稿的背景要挪,用 `make_r18.py` 的做法:原图整体左移,AI 只补画右侧,接缝放在底板挡住的地方,顶边露出的那条单独找两边最吻合的一列接。

## C. 交付流程(之前反复返工的点)

- 先跑清单 → 修完 ✗ → 再给用户看;不把已知问题交出去等用户发现。
- **只交 Figma**(10-29):切完放进用户给的那一页,版式照 S18 661:2069(S 级 666:2091 / A 级 757:2042),给本地路径 + 链接;装扮备份到 xisi 1:4 对应分区(先比哈希)。不出 unitypackage、不碰主工程。
- **装扮在 Figma 里一律放进命名画框**(11-06「没有像入口那样有名字,以后都要加名字」):头像框 1 / 名字底 1 / 称号 1 / 气泡框 1 / 主页皮肤入口图标 1,画框 = 游戏尺寸(256 / 447×130 / 304×72 / 195×133 / 300),里面放整画布静态图,不放紧边裁好的图。
- 交付件按级别核对(10-29):S = 4 底板 + 头像框 + 称号 + 名字底 + 气泡框 + 入口图标,背景物件有动效;A = 4 底板 + 入口图标 + 头像框或称号,背景静态。
- S 级分层(10-29):背景里要动的物件、头像框 / 称号 / 名字底 / 气泡框的装饰件,每个单独一层(结构完整、底下补全),不画死在底图里。
- 主题装饰在左区,不进底板安全区(xisi 778:4227)。
- 不覆盖以前的方案,新版另起文件夹 / 画板。例外(11-05):返工改其中几层 / 几件,Figma 里直接在原分区原位替换,不另放旁边。
- 用户的新反馈:先归到上表某一行改阈值或加一行,再改图——让下次自动查得出来。
