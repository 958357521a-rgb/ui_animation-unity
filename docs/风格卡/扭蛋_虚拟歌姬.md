- **甜酷(10-29 晚用户定,覆盖上一条的「酷」偏向)**:参考 氛围参考_甜酷_*。三色为主:黑 / 深莓 + 亮粉 + 白,青只做极少点缀;小恶魔元素(恶魔角、爱心、四角星闪、星星气球黑白粉混搭)+ 偶像元素(黑胶唱片、话筒、音箱)+ 平面图形纹(菱格 / 棋盘格);道具贴纸感、粗描边、造型 Q;甜 = 形状和配饰,酷 = 黑色和高对比
- **第 6 轮(10-29 用户选 v5_01 深色黑胶后定)**:黑胶身后不要白色爆光,改中等明度的莓粉柔光;光源 = 顶部聚光灯光束打到台上;道具不做贴纸(不要白粗描边),像真实舞台器材放在圆台旁边,透视比例正确、有接触阴影和地面反光;道具渲染手法和角色模型一致(光面 3D 卡通渲染、柔和明暗、亮面高光),不要太卡通平面

- 角色识别色:霓虹玫红 #FF3D9A、发色粉 #F28DB8 / #E5B8CC、机甲黑 #2A2328、纯白发光、眼睛青 #5EE6E0

- 主背板:模型身后一个由光构成的大而简单的轮廓(全息光环 / 几何光框带一点猫耳尖 / 星形霓虹框 / 声波环),像光环框住角色;不照搬她的耳机放大;背板身后一团粉色光晕是全图最亮处
- 两侧:悬浮全息屏、声波光条、发光音箱阵,往外渐小渐暗渐虚;底角虚化的粉青光棒海;空气里薄雾和光点;四周略压暗
- 顶部:一排舞台射灯 / 桁架横梁做上边框,光往中心打;天空保持干净(标题和顶栏在上面)
- 地面:深色光面舞台 + 发光透视网格汇向中心,前景圆台一圈玫红灯环,淡倒影;按钮背后平稳
- 背景配色(放宽模板亮部目标):夜 = 深靛紫 #1E1A3D→#3A2560 近台转粉;黄昏 = 桃粉地平线→薰衣草→深紫;玫红 320° 做主光,青 #5EE6E0 做对比光;黑只做细结构线,模型身后不放大黑块;左上标题区天空平缓
- 有角色版:角色出现在右侧(character_slot)的小屏 / 全息框里,不进主背板(主背板留给模型)
- 禁止:文字和字母、白天白云、实体乐队乐器、照搬角色配件放大、模型身后大黑块、满屏同亮度炫光、写实材质、圆润软萌道具
