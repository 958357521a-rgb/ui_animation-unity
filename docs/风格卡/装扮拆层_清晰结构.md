# 装扮拆层:每层结构清晰、边缘干净(11-04)

参考:`装扮拆层_清晰结构_参考/机甲风拆层参考.png`(紫色机甲头像框 / 气泡框:左整件、中拆出的部件、右只剩底框)。反例:`虚拟歌姬v5拆层_不合格.webp`。

- **底框单独看是一件完整设计**:环 / 框的分段、倒角、高光条、内描边都画全,原来被装饰盖住的地方也是同一套结构接上——不是"挖掉装饰后补的",没有残边、白渣、补丁块、灰色轮廓。
- **部件是独立小件**:四角星、行星、翅膀 + 圆盘各自描边闭合、色块分明(平涂 + 1~2 档硬阴影 + 少量高光),边缘利落像矢量;没有半透明羽化边、没有带走的底框碎片。
- 风格:扁平赛璐璐 / 矢量感,粗细一致的深色外描边,块面清楚;不是厚涂、不是噪点质感。
- 做法:部件和底框都**重画**(不从效果图抠):底框按原形状去掉装饰重画;简单几何件(竖条、横条、星点)可直接用代码画矢量;复杂件(音响、飘带、旗子)单独放绿底交 AI 重画,对齐回原位;效果图 = 底框 + 部件叠出来。
- 提示词底稿:`clean flat vector game UI asset, crisp closed dark outline of even width, flat color blocks with one hard shadow tone and a small highlight, sharp edges, no texture, no glow, no soft gradient, isolated on solid #00FF00`
