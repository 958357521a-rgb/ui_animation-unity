# 风格卡

参考图看一次就够:Claude 第一次看完一批参考图,把风格写成一张文字卡片存在这里,之后生图、改图、和设计讨论都引用这张卡片(文字只占几百 token,而图片每张一两千 token、而且会一直留在对话里)。

- 文件名:`<名字>.md`,如 `中秋桂月.md`;参考图原文件放同名文件夹 `<名字>_参考/`(生图时用 `--ref docs/风格卡/<名字>_参考/` 传给 nano,脚本自己读文件,不进对话)。
- 写法(≤20 行):

```
# 风格卡:<名字>
- 用于:<哪个任务 / 哪类资源>
- 主色:#xxxxxx(用在哪)、#xxxxxx、#xxxxxx;点缀色:#xxxxxx
- 材质 / 质感:<如:半透明果冻、磨砂、金属描边>
- 光影:<光源方向、高光形状、阴影软硬>
- 线条 / 描边:<粗细、颜色、有无内描边>
- 形状 / 构图:<圆润 / 硬朗、对称、留白>
- 元素:<反复出现的装饰元素>
- 禁止:<不要出现的东西,如:文字、写实人脸、深色背景>
- 参考图:<名字>_参考/ 共 N 张;最像的是 2、5 号(sheet 编号)
- nano 提示词底稿:<一段可以直接拼进提示词的英文 / 中文风格描述>
```
