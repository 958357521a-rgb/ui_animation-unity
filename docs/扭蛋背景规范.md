## 3. 场景结构(每期换内容,不换位置)

1. **天空**(y 0–570):占上半部分,干净,给标题和顶栏。
2. **地平线 y≈570**:远景建筑 / 城市剪影压低在这条线附近,不高过 y 400。
3. **左框景** x 470–1010、y 120–800 / **右框景** x 1760–2436、y 120–920:本期主题的大道具(圣羽是翅膀 + 光环门),**质感和暗部都放在这两组上**。左框景外侧会被列表盖住,主体要露在 x 470 以右。
4. **圆形舞台**:椭圆 x 290–2190、y 730–1100,模型站在中心;舞台边缘可用本期主色做光圈。
5. **有角色版的角色位**:右框景内 x 1960–2380、y 260–740(屏幕 / 全息框 / 光环门里)。不碰模型、标题、奖励格。

## 4. 配色(从模板量出,脚本按这个判)

| 项 | 模板实测 | 目标 |
|---|---|---|
| 亮部(V>200) | 92% | ≥60%:整体是高调浅色,UI 和模型才读得清 |
| 暗部(V<100) | 0% | ≤10%:只做框景道具里的小块压重 |
| 饱和色总量 | 28% | ≤45%:主题色只上在道具、灯带、舞台边,不要铺满 |
| 主色相集中度 | 210° 一个色相 | 饱和色里 ≥60% 是本期主色相 |
| 对比色 | ~0% | 2–12%:灯光、点缀 |

本期主色相、对比色、压重色写在本期风格卡里。某期要放宽(比如更暗的主题)也在风格卡里写明。

## 5. 质感要求

- 每种材质的高光不一样:金属硬边高光、屏幕点阵、霓虹外发光、地面半反射倒影。
- 前景 / 中景 / 远景要分开:框景道具最实,远景剪影降低对比,用空气中的光柱 / 星闪 / 光点做层次。
- 细节密度集中在左右框景,中心和 UI 背后保持安静。
- 不写任何文字(AI 写字会变形)。

python dev/gacha_bg/gacha_check.py exports/gacha_bg/<期名>/<图>.png
