## 二、「覆盖到 Unity」替换旧面板踩过的坑(207 → Sign 一路踩出来的)

每次覆盖新面板前逐条对照;生成器里已修的别改回去。

1. **根节点必须有 BasePanel**:框架 `UIWindowModule.CreatePanel` 找不到就报 "Can not find BasePanel script",界面残留在画布上、按钮全不响应。生成器在目标是面板时自动带 `<模块>Panel` 外壳。
2. **业务逻辑写在手写的 `<模块>Panel.Logic.cs`**,工作台不生成、不覆盖。原作者会在 Unity 里整个删掉模块目录再覆盖,Logic 会跟着丢 → 症状"还是设计稿占位数据、按钮没反应",Editor.log 满是「还没接业务逻辑」。副本放 `unity-reference/<模块>/`,改完同步;主工程缺 Logic 时覆盖会从副本自动带入。
3. **不影响服务端数据**(原作者原话):Logic 只读旧面板已有接口,领取等请求逐行照搬旧代码,不新增请求。
4. **"不等服务端就弹成功"**:设计稿按钮常接成直接打开「领取成功 / 确认兑换」弹窗,Logic 里要 `RemoveAllListeners` 换成走旧流程。
5. **设计稿卡片数 ≠ 服务端档位数**:按金额对齐;服务端多出的档复制卡片补上,设计稿多出的隐藏 + 报错。
6. **排版不能读 localPosition**:父节点刚改尺寸时子节点位置下一帧才更新 → 卡片挤成一团。只用锚点坐标算;打开时 `StopMovement` + 滚到最左,数据到之前隐藏内容、到了再淡入。
7. **动效不能缓存设计稿位置**:Motion / ClickFeedback 只叠加偏移、播完撤掉自己那部分,GrowX 用 x 缩放(否则打开时卡片左右闪)。
8. **切页露底**:新页盖在旧页上滑入、旧页保持不透明直到结束。
9. **贴图名大小写冲突**:Windows / Unity 不区分大小写,导出已按不区分大小写去重 + 同内容合并。
10. **编辑器开着**:主工程不能 batchmode;C# 用 Unity 自带 Roslyn 对 `Library/ScriptAssemblies` 离线编译(4.7.1-api + `-nostdlib+` + PackageCache 的 Newtonsoft)。日志在 `%LOCALAPPDATA%\Unity\Editor\Editor.log`。
11. **面板 vs 子视图**:充值界面里的标签页(如钻石页 GemPackView)是被父面板实例化的子视图,不能带 BasePanel 外壳,改生成 `<模块>Controller` + 手写 `<模块>Controller.Logic.cs`。一个 Figma 模块别混进别的界面的页面(钻石商城页曾被塞进 207 的 Sign 模块)。

## 三、测试和环境的坑

- 测试一律用隔离环境:`budui-studio-test`(8792)或 data: 快照页。8791 是日常工作地址,同地址标签页共用一份任务数据,在别的标签页点界面会覆盖用户的改动。8792 和 8791 共用 `projects/`、`exports/`,测完删测试文件。
- 改了 `studio_server.py` 要重启服务;改了 html 要刷新页面(否则拿到旧版)。
- Bash 命令里的 `\n` / `\\` 可能被 shell 钩子改写:含反斜杠的 JS 写成文件再用 node 跑。
- 浏览器面板隐藏时截图常超时;关掉的 dialog 会留在 DOM,测试只找 `dialog[open]`。
- 主工程很大,`git status` / `du` 会超过 2 分钟,放后台跑。
- 原作者电脑上 PATH 里的 `python` 是 WindowsApps 占位程序(没输出、退出码 49 / 9009),要用真实解释器;Python 打印 ✓ 等字符会因 GBK 控制台报错,脚本里先 `sys.stdout.reconfigure(encoding="utf-8")`。
- 子代理冷读文档很有效,两轮找出十几处真实问题(交付包放置违反 GameUI 程序集规则等)。

## 四、AI 重绘(统一旧界面风格)

**工具**:`dev/restyle/restyle.py`(ComfyUI + Qwen Image 2.1 Image Edit 官方接法:UNET → QwenImage21Cache、CLIP qwen3vl_8b、`TextEncodeQwenImage21` 的 `images.image_N`、KSampler 25 步 cfg 1;image_1 = 旧图,其余 = 参考图;每张约 22~26 秒,输出带真透明通道)、`prefab_sprites.py`(列 prefab 用到的切图)、`swap_in_place.py`(原路径换图,默认演练)。

**两条路要分清**:
- 「原地换图」:同路径同尺寸替换 PNG,`.meta` 不动 → GUID、九宫格、图集、prefab 引用全不变。只换皮,不动结构。
- 「工作台重做 + 动效 + 覆盖」:Figma 出新稿 → 工作台导入 → 覆盖到 Unity。改结构、加动效时用。

**做法和经验**(10-10 xisi 第一阶段 8 个界面):
- 模板 = 207 + 钻石页新稿;样式板 `dev/restyle/templates/style_swatch.png`。整屏效果图(提示词 `dev/restyle/prompts/整屏效果图.txt`,`--res 1536`)只能用样式板做参考,用整页模板会被照抄。
- 切图重绘的参考图 = 该界面的整屏效果图 + 样式板,加 `--keep-shape`。
- 整屏效果图会改文字数字、把金卡改紫、抹掉背景角色——只能定方向,真正落地要拆到单张切图。
- **能重绘**:底板、卡片、按钮底、标签底、进度条、气泡。**别重绘**:图标、道具、货币、角色、光效、遮罩、带文字的标题(文字会被画乱)。`prefab_sprites.py` 的"跳过"判断不准(`char` 会误配 `_charge`,`item` 会误配卡片底,`20PinkCoins` 认不出是货币),要人工看总览图再挑。
- **提示词要"保主色"**(`dev/restyle/prompts/切图_保主色.txt`,用法 `--prompt "$(cat 那个文件)"`):黄还是黄、灰还是灰、粉还是粉。不加的话粉卡会被画成紫卡;只换材质,轮廓、比例、透明区不变。
- **深色区域要保持深色**(同一个提示词文件的最后一句):卡片底部的黑色价格带、深紫栏底上要压白字,画浅了白字就看不清。
- **极端长宽比要补边**(`--max-aspect 2.5`):265×31 这种直接送会把参考图贴进去。很细的线(1780×57)别重绘。
- `--keep-shape`:新图透明通道不超出旧图轮廓,保证能原路径替换。
- **防照抄检查会漏**:小尺寸进度条、药丸底这类简单图形,模型常把参考图整块抄进去(10-10 漏判过 2 次:一条进度条、一个黄药丸底)。出完一定看 `_compare.png`。进度条只给样式板做参考也会抄,重绘不成功就沿用旧图或第一版。
- `_compare.png` 是每次运行时生成的;同一目录里单独修过的图不会更新它,核对以实际文件为准(10-10 就因为看了过期的对比图说错过一次)。
- 换图前查共用:`swap_in_place.py` 会按 GUID 搜整个 Assets,列出还有谁在用这张图。和别的界面共用的(如 `signIn_bg.png` 签到 / 热更界面也在用、`vip_buy_btn.png` 10 个 prefab 在用)不要按单个界面改。
- 原作者电脑:ComfyUI 便携版在 `D:\ComfyUI_windows_portable`(8188);8189 是别的项目(换色贴图工作台)的 ComfyUI,别用。
