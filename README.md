# BUD UI Studio · 预制体工作台

**本地单文件软件**(零安装零依赖):双击 `BUD_UI_Studio.html` 用 Edge/Chrome 打开即用。
把 Figma 切图摆成界面、配上动效交互,一键导出 **BUD_CHINA 主工程直接可用的预制体交付包**。

> 第一次在新电脑上用(或把文件夹交给同事):先看 `ONBOARDING.md`,双击 `安装与自检.bat` 检查环境。用 Claude Code 打开本文件夹,对它说「按 ONBOARDING.md 帮我把工作台跑起来」即可。工程文件(`projects/`)不在 GitHub 仓库里,从原作者的 U 盘或局域网共享拿。

## 工作流(三步)

1. **从 Figma 获取界面**(三种方式):
   - **Figma 插件(推荐方向,但还没在真实 Figma 里装过,原作者暂缓推进)**:安装 `figma-plugin/`(见其中 README,1 分钟)→ 在 Figma 选中界面或整张总览画板 → 运行「BUD UI Studio 导出」→ 回到这里点「**导入插件包**」。不消耗 Figma 调用额度,查看/协作席位也能用。
   - **粘贴链接拉取**:画板链接 + Figma Token →「拉取画板」。受 Figma 账号调用额度限制:查看/协作席位每月只有极少次数。
   - **手动**:Figma 导出 PNG →「导入切图」,配合「底图对照」按稿对位。

   拉进来后按图层逐个还原:思源黑体 / Noto Sans SC 的文字保留为可编辑文本,其余渲染成切图;开了裁剪且内容超宽的分组还原为横向或纵向滚动区。
2. **编辑**:点「✦ 一键配动效」,模块里所有页面一起按图层角色重新配好动效和交互,并重新连好页面跳转(会覆盖手动改过的交互设置,Ctrl+Z 可撤销):背景淡入、返回按钮设为关闭、卡片每隔 55 毫秒依次弹入、进度条从左生长、按钮弹入、金额和档位文字设为动态文本。之后可以逐个微调:拖拽、拉伸、九宫格锚点、滚动方向、点击事件标识。按 `▶` 实时预览。
   **整张总览画板 = 一个模块(主页 + 详情页 + 弹窗)**:插件包里有多个界面、或「拉取画板」的链接指向总览画板时,会列出全部界面让你勾选(默认全选,「交付说明」这类说明页不勾;主页按名称自动选「总览 / 主页」,可改),一键整体导入(一次读结构、一次渲染切图,省额度)。含 `Modal/Mask` + `Dialog/…` 图层的界面会自动识别为弹窗,只导入遮罩和对话框。导入后每页自动配好动效和交互,并连好跳转:奖励卡 → 对应详情页、规则链接 → 规则弹窗、领取 → 领取成功弹窗、确认兑换 → 确认兑换弹窗 → 兑换成功弹窗;返回键逐级返回,弹窗里的关闭/取消/知道了/确定都会关闭弹窗。
   模块里已有页面时,默认「补充到当前模块」:只加入还没有的界面,已有页面和手动改过的跳转保持不动;也可以选「重新导入为新模块」全部重建。之后要补界面,也可以用左侧「页面」列表的「＋加页面」。

   **防误改**:从 Figma 导入的布局默认「🔒 锁定」,只能选中不能拖(需要调位置时点按钮解锁,拖动超过 4 像素才生效);「↶ 撤销」/ Ctrl+Z 撤销上一步;「↺ 还原 Figma 布局」把本页位置尺寸恢复成原稿,动效交互保留。
3. **试玩测试**:点「▶ 试玩」,画布变成模拟真机(从主页开始,点卡片滑入详情页,弹窗叠在当前页上方):
   - 点按钮会播放点击反馈动效,并执行点击后的行为;
   - 卡片区可以拖动或用滚轮滑动;
   - 点试玩条上的「事件日志」展开(默认收起,未读条数显示在按钮上),实时显示程序会收到的回调,例如 `onAction("cardHair")`、`onCloseRequested()`;
   - 按 Esc 退出。

   每个可点击元素都能在属性面板设置:
   - **点击反馈**:按下缩放 / 点击弹跳 / 点击抖动 / 点击闪烁,旁边「试一下」可以直接预览;
   - **点击后**:仅触发事件 / 打开页面 / 打开弹窗 / 切换显示隐藏 / 显示节点 / 隐藏节点 / 切换数字遮罩(金额变成 `***`)。弹窗类内容勾选「初始隐藏」后,由按钮「显示节点」打开。

   这些设置导出时会原样生成到 Unity:`模块名ClickFeedback.cs` 负责点击动效,`模块名View.cs` 负责显隐和遮罩,效果和试玩时一致。
4. **导出交付包**:填模块名(英文)→ 生成 `模块名.unitypackage`(浏览器下载;通过本地服务 `dev/studio_server.py` 打开时还会另存一份到文件夹里的 `exports/`)。在 Unity 里双击或 Assets → Import Package → Custom Package 导入,文件自动落到主工程规范的目录。

每个改版任务单独一份工程(左上角任务名 → 任务首页:新建 / 切换 / 管理),连同贴图自动保存在浏览器本地(IndexedDB),刷新或重开页面会回到上次的任务;「清空画布」只清当前任务,删除任务先进回收站。

## 交付包里有什么(全部由生成器保证合规)

`.unitypackage` 导入后的落点(按《UI预制体替换规范》§3,与试点 RechargeRewards 同结构;meta / GUID 随包,prefab 里的引用导入即生效):

```
Assets/Scripts/UI/UIPanels/模块名/     (GameUI 程序集)
  模块名View.cs           ApplyServerState + onAction/onCloseRequested/onPageChanged 契约,含点击后的显隐/遮罩/跳页
  模块名Motion.cs         进场动效,unscaled,SetReducedMotion
  模块名ClickFeedback.cs  点击反馈:按下缩放/弹跳/抖动/闪烁
Assets/Arts/UI/UIPanel/模块名/
  Art/                    切图 PNG(sprite 单图模式)
  Prefabs/模块名.prefab   Layer 全 UI、根节点全屏拉伸 scale=1、字体=主工程同 GUID(思源黑体/Montserrat)、
                          装饰图自动关 Raycast、View 字段已在 prefab 里接好线(零 transform.Find)
  README.md               按钮事件表 + 动态文本 key 表 + 接入指引
```

生成器自检报告只在导出弹窗里显示,不进包。

主工程接入(还没走通过,步骤见 `ONBOARDING.md`「接入主工程」):导入 `.unitypackage` → 建图集 / Loadable 壳 / BasePanel 外壳 + Adapter → 跑 `BUD工具/UI导入体检` 复核。

## 说明

- 工程可"保存/载入"(.budui.json,含贴图);浏览器另有布局自动保存兜底
- `dev/plugin_selftest.js`:在本机模拟 Figma 环境测试插件导出(`node dev/plugin_selftest.js`,改插件或还原规则后必跑,需要 Node 20.15+)
- `dev/offline_check.js`:不开浏览器校验真实工程的导出结构(`node dev/offline_check.js`,改生成器后跑;加 `--reconfigure` 可预览「✦ 一键配动效」会改动哪些设置)
- 规范依据:https://claude.ai/code/artifact/655a23b1-ab6d-4bf0-8f99-8c2b34a1740e(原作者的私有在线文档,打不开时以 `docs/UI预制体替换规范.md` 为准)
- 生成模板逐字段对齐主工程 Unity 2022.3.32f1 原生序列化格式(2026-09-29 提取)
