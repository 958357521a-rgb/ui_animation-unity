三步产出可用预制体

①在 Figma 里选中界面(或整张总览画板)→ 运行插件「BUD UI Studio 导出」→ 点「发送到工作台」,这里会自动弹出导入提示(不用 Token,也不用下载文件;备用:下载 .budfig.json 后点「导入插件包」)——整张总览画板一次导入为一个模块(主页 + 详情页 + 弹窗),图层、文字、位置自动还原,每页按角色配好动效和交互并连好跳转(不消耗 Figma 额度)
②微调布局,给节点配动效(淡入/弹入/呼吸…)、标记按钮事件和动态文本
③填模块名 → 「导出交付包」,得到 .unitypackage,在主工程里直接导入
↺已经有做好的工程?点左上角任务名 →「从共享文件夹载入」或「从工程文件导入」,会加成任务。从别的浏览器搬过来:在原来的浏览器里任务首页点「导出全部任务」,再到这里「从工程文件导入」选那个文件
也可以粘贴画板链接 + Token「拉取画板」(受 Figma 账号调用额度限制),或手动「导入切图 PNG」
